# DreamCo Forecasting + Unmatched Sandbox Boot Camp

## North star

DreamCo's end goal is not merely to match today's AI. Every division should learn to forecast what AI, tools, workflows, datasets and user jobs are likely to matter next, test those hypotheses, and turn verified wins into shared capabilities. Forecasts are probabilities with scored accuracy, not promises.

## What is already proven

The repository-controlled fleet sandbox currently records 1,051 canonical bots and 8,408 declared capability contracts passing. That is the bot-contract baseline. It does **not** mean all external providers, all tools, every repository file, every professional workflow, or the owner-designated 500-resource catalog are already connected and certified.

The repository test registry already inventories code, tests, provider adapters, workflows, documentation and reference assets. The next layer is to bind every useful item to an owner, executable purpose, benchmark and evidence state.

## Benchmark ladder

Every capability progresses through: declared -> bound -> smoke-tested -> sandbox-tested -> adversarial-tested -> competitive -> domain-quality -> efficiency -> rights/security -> certified -> monitored -> regressed/reopened when evidence changes.

Every suite receives a Benchmark Master and an ETA estimate. Independent suites run concurrently up to the safe worker limit. Work sharing a canonical writer, external rate limit, paid budget or dependency is serialized. "Instantaneously" is treated as **start all independent work immediately and maximize safe parallelism**; claiming literal simultaneous completion would be false.

## Timeframes

Each benchmark plan stores low/base/high engineering-worker-hour estimates. Calendar estimates are computed only after two real batches establish measured throughput. Initial planning bands:

- metadata/small deterministic fixture: 0.1-0.5 worker-hours
- tool/adapter contract: 0.5-4 worker-hours
- new shared capability: 2-16 worker-hours
- complex professional/domain suite: 8-40 worker-hours
- external provider certification: 1-8 worker-hours plus approval/provider wait time

The build meter should report remaining worker-hours, parallelizable hours, critical-path hours, blockers, and low/base/high calendar ETA.

## Repository-wide sandbox

The boot camp must cover bots plus shared runtime, tools/functions, adapters, routes, APIs, databases/state, queues, workflows, generators, client/server modules, provider adapters, schemas, configuration, deployment, observability and security. Each useful reference asset/document is assigned one disposition: keep reference, extract requirement, convert to schema, convert to fixture, convert to code, archive, or owner-approved deletion. Conversion never means blindly turning prose into executable code.

## 500-resource connection auditor

For the owner-designated 500 AI resources, build one canonical registry with these states: `declared`, `metadata_verified`, `adapter_exists`, `credentials_or_access_available`, `sandbox_reachable`, `capability_tested`, `certified`, `blocked`, `not_applicable`. A resource is never called "connected" from catalog metadata alone. Each entry needs source/version, access method, auth requirements, capabilities, owner, adapter, health check, benchmark suite, last test, cost/rate limit and blocker.

## Continuous capability leads

Every division continuously receives new benchmark leads from forecast signals, model/API/tool releases, open-source changes, new datasets, user failures, customer requests, job/task taxonomies, competitor changes and repository gaps. Leads become sandbox fixtures before becoming product claims.

## Hollywood, music and advertising

Buddy Creative Studio should cover the full professional workflow: development, writing, producing, budgeting/scheduling, directing/previs, picture, VFX/animation, editorial, color, dialogue/ADR/Foley/mix, composition/music supervision, localization/accessibility, QC, marketing and distribution. Music adds artist development, songwriting, production, recording, mixing/mastering, metadata, publishing/sync/release/tour/fan workflows. Advertising adds strategy, creative, broadcast/radio/CTV/digital/social/OOH/podcast workflows, trafficking, measurement and optimization.

Professional quality benchmarks include temporal visual consistency, edit continuity, cinematic composition, audio intelligibility/loudness, mix translation, music originality/provenance, technical QC, brief adherence, brand consistency, CTA/message effectiveness, platform delivery specs and measurable campaign experiments. Human approval remains required for publishing, ad spend, contracts and rights-sensitive releases.

## Dataset training business

Treat dataset quality as a product strength: provenance, license/commercial rights, schema, duplicates, PII/secrets, malware, contamination/leakage, coverage, bias/limitations, freshness, reproducibility, retrieval usefulness and benchmark usefulness. Every sellable dataset/data package needs a data card, lineage, rights record, quality report, version, benchmark evidence and deletion/correction process.

## Definition of 'never stop learning'

DreamCo runs bounded scheduled/event-driven discovery and sandbox cycles indefinitely. A mastered capability is reopened when its code, dependency, model, provider, dataset, benchmark, threat model or freshness window changes. This avoids an unsafe infinite process while preserving continuous improvement.
