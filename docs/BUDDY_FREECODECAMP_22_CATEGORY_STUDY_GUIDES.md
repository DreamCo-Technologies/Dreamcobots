# FreeCodeCamp 22-category study guide drafts

This pack adds an original category-level learning guide for each of the 22 subject categories in DreamCo's FreeCodeCamp metadata catalog. It covers computer science, HTML/CSS/accessibility, JavaScript/TypeScript, frontend, backend/APIs, Python, Java/JVM, systems programming, databases/SQL, data science, ML/DL, generative AI, agents/MCP, cybersecurity, Linux/IT, cloud/DevOps, mobile, games, mathematics/statistics, career preparation, software architecture/testing, and unclassified resources.

Each category has a learning goal, four ordered units, a capstone, an assessment, evaluation dimensions, and evidence requirements.

## Source completeness

The catalog currently reports a partial inventory with 1,740 observed videos. These category guides are useful internal curricula, but they do not prove that every public freeCodeCamp video or historical course is represented. The separate provisional-queue workflow preserves that limitation.

## Rights and completion

All guides are original drafts and remain `original_category_guide_draft_needs_human_review`. Official video/course links are references only. Transcript, media, redistribution, and model-training rights require separate permission. Reading or metadata cataloging is not mastery.
