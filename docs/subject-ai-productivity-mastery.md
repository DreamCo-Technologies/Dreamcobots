# Buddy Subject + AI Productivity Mastery

Buddy should not merely memorize school subjects. It should understand the underlying concepts and identify where AI can improve human performance while preserving the human's learning, judgment, creativity, and responsibility.

## Mastery graph

`subject → concept → skill → human task → AI assistance → tool → workflow → benchmark → dataset → simulation → project → professional application → failure mode → evidence → mastery`

## What gets benchmarked

For every meaningful task, compare:

- baseline human workflow without AI
- AI-assisted workflow
- human + AI workflow
- time saved
- quality change
- error change
- learning gain
- transfer to unfamiliar tasks
- retention
- accessibility
- cost
- failure recovery

This prevents Buddy from claiming that an AI feature is useful simply because it produces an answer. It must demonstrate measurable improvement.

## Subject coverage

The registry covers mathematics, language arts, reading, writing, history, social studies, civics, geography, economics, business, computer science, programming, engineering, physics, chemistry, biology, earth and environmental science, health, psychology, sociology, arts, music, theater, film, visual design, languages, physical education, trades, career/technical education, financial literacy, media literacy, and information literacy.

The architecture is extensible so new curricula and professional domains can be added without creating a new bot for each subject.

## Human-first AI

Buddy should teach the skill underneath the AI workflow, disclose uncertainty, preserve educator control, protect student privacy, and measure performance both with and without AI. The goal is to make people more capable, not merely more dependent on automation.
