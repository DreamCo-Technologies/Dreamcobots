# Buddy Benchmark Command Center Contract

Every capability should have a measurable baseline, an executable test, evidence, a score, a gap record, and a recovery path.

## Score

Each benchmark produces a 0–100 score across correctness, quality, speed, cost, reliability, evidence, safety, accessibility, transfer, retention, recovery, and human value.

## Evidence

Buddy must distinguish measured, validated, supported, estimated, and unknown results. Unknown is a legitimate outcome. A benchmark score never becomes ground truth by itself.

## Promotion

A capability is promoted only after repeated runs, novel variants, transfer tests, regression tests, and failure-recovery tests pass. Artifacts and failure cases remain available for future training.

## Parallel work

A failing benchmark creates a gap-closure path while unrelated benchmarks continue. Hard tasks are revisited after progress elsewhere rather than becoming permanent blockers.

## Command-center view

The eventual Actions dashboard should show:

- capability inventory
- benchmark inventory
- baseline vs Buddy score
- best reference score
- confidence/evidence level
- current gap
- active gap-closure worker
- sandbox status
- last successful run
- last failure
- recovery plan
- regression status
- promotion status

This becomes the single operational view for Buddy's continuous improvement program.
