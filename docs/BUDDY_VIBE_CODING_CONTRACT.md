# Buddy Universal Vibe-Coding Contract

Buddy's vibe-coding experience is a universal creation interface, not a template-only generator.

## User experience

A user may describe, speak, or provide an authorized image of an idea. Buddy identifies the creation target, presents multiple implementation examples, explains tradeoffs, creates a project plan, and then builds through a sandboxed evidence-gated pipeline.

Supported targets include games, large simulations, apps, websites, software, APIs, prototypes, courses, teacher-created learning experiences, business plans, franchise relationship models, commercials, music videos, films, AI projects, and custom projects.

## Build-and-learn loop

`Idea -> examples -> requirements -> design -> generate -> sandbox -> test -> review -> version -> preview -> teach -> iterate`

The user can continue the project conversationally: change features, add capabilities, alter lessons, redesign interfaces, request multiplayer, convert prototypes between supported targets, or ask Buddy to explain generated code.

## Learning while building

Each project may expose a learning track with explanations, guided modifications, challenges, and mastery evidence. Verified build outcomes may inform the learning/evaluation system; unrestricted self-modification is not permitted.

## Quality contract

Generated output is not considered production-ready merely because generation succeeded. Security, privacy, rights/provenance, automated tests, performance and appropriate human approval are explicit gates. Failed experiments remain evidence and tests must not be weakened to manufacture a green result.

## Multimodal rights

Voice and image inputs are supported at the interface level. Publication workflows must track provenance and appropriate ownership, licensing, public-domain status, or consent for likeness/voice use.

## 500-model collaboration

The model council can provide specialized proposals and reviews for architecture, coding, education, game design, security, testing, performance, media, NPC behavior and AI trust. Model recommendations are evidence-ranked and benchmarked rather than automatically trusted.
