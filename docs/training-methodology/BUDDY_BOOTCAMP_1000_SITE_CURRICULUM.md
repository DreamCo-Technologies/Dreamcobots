# Buddy Bootcamp — 1,000-Site Capability Curriculum

## Objective
Turn the repository's 1,000-site/benchmark target universe into a structured training product. A site is a curriculum source, not an automatic mastery claim.

## Per-site learning cycle
1. Discover and classify the resource.
2. Capture allowed public learning material and provenance.
3. Extract concepts, procedures, examples, and constraints.
4. Generate practice tasks from the material.
5. Run tasks in an isolated sandbox.
6. Test the same skill on held-out/transfer tasks.
7. Score against a reproducible rubric.
8. Cluster failures and generate remediation.
9. Re-test and check regression on protected skills.
10. Record evidence, source provenance, score delta, and resource cost.

## 1,000-site curriculum states
Each site must have one of:
- DISCOVERED
- CLASSIFIED
- CURRICULUM_BUILT
- PRACTICE_READY
- SANDBOX_TESTED
- TRANSFER_TESTED
- VERIFIED
- REGRESSION_REVIEW
- BLOCKED

`VERIFIED` requires reproducible evaluation evidence. Reading or crawling a site never equals mastery.

## Training package output
For each site the commercial package can contain:
- Source/provenance record
- Capability taxonomy
- Lesson/curriculum
- Practice tasks
- Sandbox tasks
- Evaluation rubric
- Held-out transfer set
- Failure/remediation set
- Scorecard
- Evidence ledger
- Version and licensing/usage metadata

## Scheduling
The scheduler should prioritize expected capability gain, benchmark gap severity, transfer value, freshness, cost, and prerequisite dependencies. Parallel work is allowed when tasks are independent; shared-state mutations remain serialized.

## Content rights
Use only material DreamCo is permitted to collect, store, transform, or redistribute. Preserve attribution/provenance and licensing metadata. Do not package copyrighted books, videos, or websites for resale merely because they are publicly reachable.

## Commercial vision
Buddy Bootcamp can become the demonstration environment for DACL: customers can select capabilities, run training, observe benchmark deltas, and purchase compliant training-data/task packages generated from DreamCo-owned or properly licensed material.
