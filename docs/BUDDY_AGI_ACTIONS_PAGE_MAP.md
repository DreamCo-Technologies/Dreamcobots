# Buddy AGI Actions Page Map

## Mission Control

**Mission → Goal → Action → Specialist → Evidence → Approval → Result → Lesson**

### Mission domains

Reasoning • Agent routing • Coding • CI/reliability • Benchmarks • Learning • Research • Memory • Multimodal • Navigation • Business • Devices • Developer Copilot • Security • Beginner UX • Observability • Releases • Professional help • Creative Studio • Human control

### Specialist workbench

Repository Explorer • Requirements Analyst • Architect • Coder • Tester • Debugger • Security Reviewer • Dependency Reviewer • Performance Engineer • UX/Accessibility Reviewer • Data Analyst • Documentation Writer • Release Engineer • DevOps/CI Specialist • Integration Specialist • Benchmark Evaluator

### Evidence

Every important result should have a source, timestamp/version, test or benchmark reference, limitations and status.

### Recovery

Failure → diagnose → select specialist → bounded repair → retest → regression test → record lesson.

### User experience

Every advanced control gets a plain-English explanation and a safe next step. Consequential actions require the configured approval boundary.
