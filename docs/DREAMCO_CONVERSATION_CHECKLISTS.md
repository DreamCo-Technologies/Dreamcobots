# DreamCo — Per-Conversation Master Checklists

**Rule:** Every source conversation has its own independent checklist. Completion in one conversation never automatically completes another. Shared implementation may be referenced by multiple conversations, but each conversation must be independently verified.

**Status policy:** All tasks begin unchecked. A task may be checked only when its implementation, tests, and evidence are recorded in the master registry. Historical checkbox edits are not treated as repository verification.

## Global rules

1. Each conversation retains its own 14-item status.
2. Shared PRs may support multiple conversations, but evidence must map to each originating requirement.
3. Duplicate requests are cross-referenced rather than deleted.
4. Failed tests remain open until repaired and rerun.
5. Blocked work records the blocker and owner action required.
6. No requirement is complete based solely on a plan, generated code, or an unchecked PR.
7. Repository and GitHub Pages changes are tracked together where relevant.
8. Cloudflare remains outside the active build path until explicitly reauthorized; no authorization or security bypasses.
