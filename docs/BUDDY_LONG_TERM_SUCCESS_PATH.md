# Buddy Long-Term Success Path

## Mission

Build Buddy into a progressively more independent open-source AI engineering system that can learn capabilities, test them, improve them, and help users create specialized AI systems.

## Development ladder

### 1. Reliable foundation
- Make Actions observable.
- Make every required check reproducible.
- Separate infrastructure failures from code failures.
- Preserve logs and artifacts.
- Add rollback paths.

### 2. Capability intelligence
- Maintain a canonical capability registry.
- Map capabilities to benchmarks, tasks, tools, sources, and datasets.
- Track gap, mastery, regression, and improvement status.

### 3. Buddy Bootcamp
- Teach capabilities through sandboxed practice.
- Require independent evaluation.
- Use holdout and transfer tests.
- Record failures as learning signals.
- Reattempt intelligently instead of repeating the same failed plan.

### 4. Source learning
- Study authorized external references.
- Record provenance and rights metadata.
- Create original DreamCo explanations, experiments, tasks, and datasets.
- Never bypass access controls or redistribute material without rights.

### 5. AI Foundry
- Let users describe the AI they want.
- Convert intent into capability requirements.
- Select architecture, models, tools, memory, retrieval, and evaluation strategy.
- Build and test the resulting AI in a sandbox.

### 6. Continuous improvement
- After mastery, search for measurable improvements.
- Run controlled experiments.
- Keep improvements only when they beat the baseline without unacceptable regressions.
- Periodically retest mastered capabilities.

### 7. Open-source leadership
- Convert proven improvements into documented, reproducible components.
- Allow owner-approved publication.
- Publish measurements rather than unsupported frontier claims.
- Feed community improvements back into the capability system where properly licensed.

## Success condition

The long-term goal is not for Buddy to depend on one assistant forever. The goal is a system that can increasingly investigate, plan, implement, test, diagnose, improve, document, and maintain itself while escalating high-impact decisions to its owner.
