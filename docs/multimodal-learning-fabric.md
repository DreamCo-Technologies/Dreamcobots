# Buddy Multimodal Learning Fabric

Books, videos, websites, and repositories now share one evidence-grounded learning architecture.

## Shared loop

`discover → normalize → deduplicate → segment → index → retrieve → reason → cite → verify → create original task → sandbox → score → regression → learn`

## Evidence requirements

- Books: page, section, or chapter pointer.
- Videos: timestamp or time range.
- Websites: URL/page identifier and retrieval date.
- Repositories: path plus revision/commit.

Buddy may state that evidence is missing or uncertain. It must not manufacture a citation or pretend to have read material it did not retrieve.

## From knowledge to capability

Each source can become a concept map, skill map, benchmark, quiz, project, simulation, game scenario, flashcard set, professional task, or regression test.

The goal is not to build a giant copy of the internet. The goal is to build an evidence-backed capability graph that lets Buddy learn concepts and then demonstrate them independently.
