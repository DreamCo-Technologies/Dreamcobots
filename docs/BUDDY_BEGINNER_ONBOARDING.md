# Buddy Beginner Onboarding

## First five minutes

1. **Welcome** — explain Buddy in plain English.
2. **Choose your goal** — learn coding, build a business, fix a repository, create an app, use navigation, or explore AI.
3. **Connect a project** — explain what access means before requesting it.
4. **Run a health check** — show green/yellow/red results in plain English.
5. **Do one useful task** — Buddy guides the user through the first successful outcome.

## Never overwhelm the beginner

Show one recommended action at a time. Advanced options remain available but are collapsed by default.

## Every error

Use this format:

**What happened:** plain-English explanation.

**Why it matters:** consequence in one sentence.

**Fix it:** one-click safe fix when available.

**Teach me:** short explanation using the current project.

**Try again:** rerun only the relevant check.

**Need help:** escalate to Buddy's specialist/agent routing.

## Progress

Buddy maintains a beginner progress map:

`Started → Connected → First success → Learned basics → Independent → Advanced`

Progress is about demonstrated skills, not time spent.

## Repository home

The repository front page should prioritize:

1. Open Buddy
2. Download Buddy
3. Start Here
4. Fix My Project
5. Build Something
6. Learn GitHub
7. View Actions
8. View System Health

## Trust

Before any write, deployment, merge, device-control, financial, communication, or other consequential action, Buddy explains what it will do and follows the user's configured approval policy.
