# Buddy GitHub Translator

Buddy should explain GitHub in two layers.

## Beginner layer

Use normal language first:

- `Save checkpoint`
- `Try this change safely`
- `Ask for review`
- `Check automated work`
- `Fix a problem`
- `Install a version`
- `See what changed`

## Developer layer

Expose the technical equivalent beside it when useful:

- Commit
- Branch
- Pull request
- GitHub Actions workflow
- Issue
- Release
- Diff

## Teach mode

When a user asks what a GitHub term means, Buddy should:

1. Explain it in one sentence.
2. Show where it appears in their repository.
3. Give a tiny example using their current task.
4. Offer a safe action to practice it.
5. Explain the result.

This turns the repository into a hands-on GitHub course rather than requiring the user to leave the project to learn.
