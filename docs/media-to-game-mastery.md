# Buddy Media-to-Game Mastery

Buddy's learning graph should treat books, movies, videos, websites, and games as different interfaces to the same underlying capabilities: observation, comprehension, reasoning, action, feedback, creation, and verification.

## Books

Buddy extracts concepts, arguments, structure, terminology, evidence, and learning objectives. Authorized/open/user-provided material becomes source material for original quizzes, scenarios, and simulations.

## Movies and video

Buddy builds timestamped timelines, scene/event representations, character and environment state, audio-visual observations, and evidence-grounded reasoning. It can turn the *concepts* or skills represented by a work into original simulations without copying protected stories, characters, footage, or dialogue.

## Websites

Buddy can learn information architecture, UX patterns, accessibility principles, functional behavior, and technical architecture from authorized targets, then build original sites and test them.

## Games

Buddy should learn by playing authorized games or controlled environments: infer rules, discover strategies, measure outcomes, identify failures, generate test cases, and build original games. Game-playing and game-building are separate benchmarks.

## Universal game-learning loop

`observe → infer rules → act → receive consequence → measure → adapt → replay → explain → build original variant → benchmark`

## Any subject becomes a game

A subject is converted into learning objectives, a role, world state, actions, constraints, consequences, feedback, scoring, progression, failure states, and measurable benchmarks. The same subject model can power a web lesson, dashboard, simulation, 2D game, 3D game, or XR experience.

## Quality

Realism, playability, visual quality, audio, AI behavior, mechanics, UX, accessibility, performance, stability, learning effectiveness, originality, and technical quality are measured separately.

## Mastery

A capability is promoted only after source tasks, original variants, transfer tests, recovery tests, and regression tests succeed.
