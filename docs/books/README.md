# Buddy Human Books

Two separate, beginner-friendly books explain Buddy's learning system and how people use Buddy.

1. [The Buddy Bootcamp Handbook — How to Learn Anything](THE_BUDDY_BOOTCAMP_HANDBOOK_HOW_TO_LEARN_ANYTHING.md)
   - A practical learning method for every subject and DreamCo division.
   - Covers freeCodeCamp-inspired active practice, progressive challenges, projects, tests, feedback, evidence-based mastery, division learning, pull-request review, and CI/CD review.
2. [The Buddy User's Guide — How to Use Buddy](THE_BUDDY_USERS_GUIDE_HOW_TO_USE_BUDDY.md)
   - A plain-language guide to asking Buddy for help, learning, building, research, tool connections, GitHub, approvals, progress, and safe operation.

These are independent DreamCo publications, not official freeCodeCamp publications or endorsements. Feature descriptions distinguish intended behavior from verified availability.
