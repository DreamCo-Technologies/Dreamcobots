# 25M CPU LLM course reference catalog

This catalog supplies the reference inventory used by the 25M CPU LLM course tests and future study workflows. It contains 42 source pointers spanning the freeCodeCamp course, Hugging Face, PyTorch, Python, tokenization research, open reference implementations, evaluation benchmarks, and dataset references.

All entries are link-only pointers with current-review pending. A catalog entry does not establish that a resource was accessed, studied, downloaded, licensed, or used for training. The catalog explicitly disables automatic downloads, transcript downloads, and training approval. Each dataset, model, software package, documentation source, and transcript requires its own rights and terms review before reuse.

The list is intentionally useful for internal study planning, not a bulk-download manifest.
