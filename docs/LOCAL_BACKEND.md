# Local backend

Local, cloud, and hybrid are modes. This file does not start a server.

## Local

Pros: files stay on the Mac. Cons: no shared adapter, and a laptop sleep stops the process.

## Cloud

Pros: the Pages site stays up. Cons: secrets must be set in GitHub, not in a file.

## Hybrid

Pros: local notes plus the public Pages site. Cons: the two copies can disagree.

## Start, stop, status

Do not run a hidden always-on process from this page. Status is the daily Actions job. Start and stop for a local process belong to the owner terminal, not a committed script with a secret.
