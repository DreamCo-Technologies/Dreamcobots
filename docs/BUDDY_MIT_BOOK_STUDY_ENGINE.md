# Buddy MIT Book Study Engine

Buddy should use MIT Press and MIT OpenCourseWare resources as **curriculum candidates**, not as proof of capability.

## Study pipeline

1. Discover books and course readings from official metadata.
2. Verify title, author, edition, ISBN, publication date and access/licensing status.
3. Map each resource to one or more Buddy capabilities and benchmark suites.
4. Select the smallest useful chapter/reading set for the target benchmark.
5. Generate original practice tasks from the concepts; never copy protected solutions.
6. Run the practice task in a sandbox.
7. Run the corresponding benchmark.
8. Measure correctness, quality, speed, safety and reliability.
9. If the result fails, generate a remediation lesson and retry.
10. Record the evidence, limitations and regression test.
11. Promote the capability only when the configured mastery policy is satisfied.

## Recommendation behavior

For any failed benchmark Buddy should be able to answer:

- What capability failed?
- Which prerequisite appears missing?
- Which MIT resource is most relevant?
- Which chapters/topics should be studied?
- What practice task should be attempted next?
- What benchmark will verify improvement?
- What evidence would move the capability from its current maturity state to the next state?

## Important boundary

Reading a book, completing a course, or passing a single test does **not** establish general intelligence or frontier equivalence. Mastery requires repeatable evidence on the task family being measured.
