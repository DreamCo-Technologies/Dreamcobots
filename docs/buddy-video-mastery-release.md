# Buddy Video Mastery Release

This release track consolidates the video-learning architecture developed in the benchmark program.

## Pipeline

Authorized source → fast inventory → parallel learning workers → evidence graph → evidence validation → quality gates → AI-readable package → benchmark → sandbox bootcamp → promotion.

## Included capability contracts

- NVIDIA reference-learning lane
- fast video inventory
- scan-efficiency benchmark
- AI-readable video manifest
- parallel video learning workers
- grounded evidence graph
- evidence validator
- capability package compiler
- knowledge quality gates

## Engineering rules

- Never bypass access controls or licensing.
- Never treat model confidence as proof.
- Preserve `unknown` when evidence is insufficient.
- Preserve conflicting observations until resolved.
- Keep failed workers isolated from unrelated work.
- Cache and checkpoint expensive processing.
- Benchmark speed and quality together.
- Record source, version, license, hashes, timestamps, worker versions, and run IDs.

## Goal

Create a portable DreamCo video-learning substrate that can support video understanding, filmmaking, music production, education, simulation, game development, and general productivity without making NVIDIA infrastructure a hard dependency.
