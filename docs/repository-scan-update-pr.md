# Repository Scan Update PR

Standardizes evidence-backed update reporting after authorized repository scans.

- Defines scan/update comment contract.
- Adds scheduled/manual read-only scan evidence workflow.
- Defines `found`, `proposed`, `changed`, `verified`, `blocked`, and `unknown` states.
- Preserves evidence and regression history.
- Connects the reporting contract to Buddy's scanner and benchmark architecture.

No code change or passing result is claimed without evidence.
