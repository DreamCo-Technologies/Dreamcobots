# Definition of Ready

A capability is ready for engineering work when:

- [ ] Problem and user outcome are explicit.
- [ ] Division owner is assigned.
- [ ] Capability ID is canonical.
- [ ] Inputs and outputs are defined.
- [ ] Data/source requirements are known.
- [ ] Dependencies are identified.
- [ ] Policy/permission requirements are identified.
- [ ] Side effects are documented.
- [ ] Success metric is defined.
- [ ] Failure modes are listed.
- [ ] Test strategy exists.
- [ ] Observability requirements exist.
- [ ] Rollback/recovery strategy exists.

A request that fails these checks belongs in planning, not production code.
