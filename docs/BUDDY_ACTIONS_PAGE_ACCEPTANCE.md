# Buddy Actions Page Acceptance Criteria

The Actions page is ready for release only when:

- mission goals load without JavaScript errors
- all 16 specialist roles render with usable buttons
- every goal action has a clear next step
- benchmark status is evidence-backed rather than invented
- workflow health is traceable to repository evidence
- failure recovery preserves logs and does not hide failures
- downloads link to verified release artifacts
- consequential actions respect approval policy
- beginner explanations remain available beside advanced controls
- automated page tests pass
- browser end-to-end verification passes
- accessibility checks pass
- build and repository CI pass

A page that looks complete but fails these criteria is not considered complete.
