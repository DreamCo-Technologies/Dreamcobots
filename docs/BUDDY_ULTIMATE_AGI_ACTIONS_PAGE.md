# Buddy Ultimate AGI Actions Page

## Purpose

The Actions page is Buddy's mission-control layer: a beginner-friendly surface that connects goals, specialist agents, workflows, benchmarks, failures, learning, releases and human approvals.

## Goal domains

1. Reasoning and planning
2. Best-agent routing
3. Software engineering
4. CI and reliability
5. Benchmark mastery
6. Continuous learning
7. Knowledge and research
8. Memory and context
9. Multimodal understanding
10. Navigation and travel
11. Business building
12. Authorized device operations
13. Developer Copilot
14. Security and governance
15. Beginner experience
16. Observability
17. Build and distribution
18. Professional help routing
19. Creative studio
20. Human control

## Page sections

- Mission statement and honest capability status
- Goal cards with direct Buddy actions
- Specialist workbench
- Evidence and benchmark layer
- Workflow health and recovery controls
- Download/device setup
- Human approval boundaries

## Operating principle

The page should make it possible to move from:

`Goal → Prospectus → Best specialist → Plan → Sandbox → Implementation → Test → Review → Benchmark → Approval → Release → Monitoring → Learning`

without hiding the evidence or pretending an aspiration is already implemented.

## AGI engineering standard

The project can pursue increasingly general capability, but the UI must distinguish:

- planned
- implemented
- experimentally demonstrated
- reliable
- mastered

No single benchmark, model score or successful demo should be presented as proof of AGI or universal frontier performance.
