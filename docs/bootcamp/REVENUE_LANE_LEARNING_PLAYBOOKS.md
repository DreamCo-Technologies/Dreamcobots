# Revenue lane learning playbooks

This catalog expands all 34 lanes in `money_os/config/revenue_lanes_expanded.json` into a task-by-task learning blueprint. Each lane includes lane-specific work, a shared six-stage execution sequence, software research requirements, benchmark requirements, guardrails, truth rules and completion evidence.

## Validate

```bash
python -m pytest -q tests/test_revenue_lane_learning_playbooks.py
python tools/validate_revenue_lane_learning_playbooks.py
```

## What this is and is not

The entries are structured learning blueprints, not completed detailed course lessons, working production integrations, legal/tax/financial advice, verified leads or revenue. Lesson authoring, source research, sandbox execution and benchmark evidence remain explicit next stages.

The playbooks require current official sources, documented rights, customer consent or another lawful basis, human approval for production actions, and transaction evidence before revenue is reported. Projections, leads, proposals, gross sales and collected net revenue must remain distinct.
