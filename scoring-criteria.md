# Scoring criteria

A weight is a choice. A benchmark score is not measured until a result is saved.

## Required, weight 3

- saved result
- same task twice
- median latency
- failure kept
- no secret
- no invented score

## Repo checks, weight 1

- success rate
- holdout
- second pass
- counterexample
- citation
- permission
- sandbox
- adapter
- telemetry
- auth
- rollback
- timeout
- retry
- cost
- 404 check
- 200 check
- approval
- human review
- schema
- lint
- link check
- age path
- work task
- home task
