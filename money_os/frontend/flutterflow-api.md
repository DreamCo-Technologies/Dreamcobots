# FlutterFlow integration contract

Build these screens against the Money OS API:

1. Home: `/health` + aggregate opportunity metrics.
2. Deals: opportunities filtered to `deal` and `coupon`.
3. Receipts: upload/OCR backend integration, then reward matching.
4. Flip Finder: `resale` opportunities with net-profit and confidence.
5. Earnings: conversion and revenue events; separate pending from paid.
6. Legal Money: settlement discovery, eligibility details, deadline, authoritative source and explicit user confirmation.
7. Referrals: referral attribution and conversion status.

Required UI fields: source, last verified time, price/coupon/cashback, estimated net profit, confidence, effort, expiration/deadline when applicable, and disclosure that estimates are not guaranteed.
