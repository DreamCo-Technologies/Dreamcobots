# Money OS frontend contract

Implement these FlutterFlow pages against the backend/API or existing DreamCo data layer:

1. Dashboard — verified opportunities, estimated savings/profit, pending actions, revenue.
2. Deals — price drops, extreme clearance, coupon stacks, price history, confidence, source timestamp.
3. Receipt Scanner — camera/upload, OCR result review, matched offers, user confirmation, rewards ledger.
4. Flip Finder — buy price, fees, estimated resale range, confidence, distance, listing source.
5. Claims — official settlement source, deadline, eligibility, proof requirement, claim status; user-controlled submission.
6. Grants/Contracts — official source, eligibility, deadline, award size, application workflow.
7. Jobs/Gigs — verified listing, estimated value, effort, application link.
8. Earnings — affiliate/service/lead revenue, user rewards, pending/completed status.
9. Referrals — referral code, qualified referral status, terms.
10. Admin/Health — source freshness, bot status, verification failures, revenue reconciliation.

Every opportunity card must display: source, last verified time, confidence, expected value, estimated effort, and a clear distinction between savings, revenue, and profit.
