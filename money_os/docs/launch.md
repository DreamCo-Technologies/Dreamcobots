# Money OS launch plan

## Revenue lanes
- Affiliate commissions from compliant product/deal links.
- Premium subscriptions for verified alerts, personalization, price history, and advanced filters.
- Qualified lead sales for permitted business, real-estate, jobs, and services workflows.
- Software/service fees for automation and business tooling.
- Marketplace fees where DreamCo operates the transaction and terms permit it.

## Do not promise
Do not advertise guaranteed earnings, guaranteed claim payouts, guaranteed resale profit, or unverified penny deals. Show expected value as an estimate and expose source/freshness/confidence.

## First production milestone
1. Connect official/authorized sources.
2. Run in dry-run and collect normalized opportunities.
3. Verify source timestamps and economics.
4. Turn on alerts only for verified records.
5. Instrument clicks, conversions, subscriptions, leads, and verified outcomes.
6. Reconcile every revenue event before reporting profit.

## Settlement/claim workflow
Discover official settlement notice -> verify deadline and eligibility requirements -> show source -> let user review information -> user submits or use only an explicitly authorized submission API -> track status.

## Receipt workflow
User uploads receipt -> OCR -> user reviews parsed items -> match authorized reward offers -> show expected reward -> user confirms any external action -> record status.

## Deal workflow
Authorized feed -> price normalization -> price history -> coupon/cashback eligibility -> fees/tax/shipping -> resale estimate when relevant -> confidence score -> alert.

## Definition of done
A bot is not considered monetization-ready because it prints an opportunity. It is ready only when it has a source adapter, verification, error handling, observability, monetization attribution, user-facing action, and outcome/reconciliation path.
