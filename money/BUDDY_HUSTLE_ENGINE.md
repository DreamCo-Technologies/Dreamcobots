# Buddy Hustle Engine

## Purpose

Give users a transparent way to ask:

> "How can Buddy help me make money?"

Buddy responds with personalized, evidence-based opportunity plans rather than promising guaranteed income.

## Personalization inputs

With user permission, score opportunities using:

- skills
- interests
- available time
- budget
- equipment
- existing business
- industry knowledge
- preferred work style
- target income
- risk tolerance
- geographic/service area
- audience/network
- existing assets

Never require sensitive information when it is unnecessary.

## Autonomy levels

### Level 0 — Ideas
Buddy only researches and explains opportunities.

### Level 1 — Recommendations
Buddy creates a ranked opportunity plan and asks before taking action.

### Level 2 — Drafting
Buddy can prepare listings, proposals, emails, websites, content and workflows for approval.

### Level 3 — User-approved execution
Buddy may execute explicitly approved actions within a defined scope.

### Level 4 — Bounded automation
Buddy may repeat pre-approved low-risk actions under budgets, rate limits, allowed services and stop conditions.

### Level 5 — Continuous optimization
Buddy can monitor approved workflows, report results, suggest improvements and request authorization for material changes.

No autonomous level permits hidden spending, deceptive behavior, unauthorized account access, bypassing platform rules, spam, fraud, impersonation or guaranteed-income claims.

## User control

Every autonomous workflow must expose:

- what Buddy plans to do
- why it is doing it
- which accounts/tools it will use
- expected cost
- maximum allowed cost
- data it will access
- actions it may take
- actions requiring approval
- stop/pause button
- activity log
- results and revenue attribution
- errors and failed actions
- rollback/cancellation options where supported

Default is **user-controlled and approval-first**.

## Opportunity scoring

`expected_value × evidence_quality × fit × automation_potential × time_efficiency / cost_and_risk`

The score is a prioritization aid, not a promise of income.

## Hustle learning loop

`user_goal -> profile -> opportunity discovery -> evidence gathering -> risk/terms check -> economics estimate -> personalized plan -> sandbox/draft -> user approval -> bounded execution -> measurement -> optimization`

Buddy should continually learn which legitimate workflows create measurable value for different user profiles and turn successful workflows into reusable capability packages.
