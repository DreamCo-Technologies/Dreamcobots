# datasets

Hugging Face `datasets` library study pack for Buddy study / future student training.
This pack teaches the *tooling* (load, transform, stream) that every capability pack
(`pack.instruct`, `pack.code`, `pack.reason`, ...) depends on. It is courseware, not a
training corpus.

- train_allowed: false
- train_in_default_ci: false
- automatic_download_in_ci: false
- automatic weight download: no
- min_native_pass_rate: 1.0 (all offline lesson examples must pass)
- teacher: xai/grok-best-available
- hand-authored: yes (not generated by `tools/build_hf_capability_packs.py`)

## Purpose

Hub literacy (Phase 1 of `docs/HUGGINGFACE_MASTERY_PLAN.md`) for the `datasets` library:

1. `lessons/01_load_dataset` — Hub loading with `revision=` pins, splits and split slicing,
   local csv/json/parquet files, `data_files`, `cache_dir`.
2. `lessons/02_map` — `map(batched=True)`, `num_proc`, `remove_columns`, fingerprint caching,
   `filter`, `with_format` / `set_format` for numpy and torch.
3. `lessons/03_streaming` — `streaming=True`, `IterableDataset`, `take` / `skip`,
   `shuffle(buffer_size=...)`, `interleave_datasets`, `Dataset.to_iterable_dataset`.

Every lesson ships a `README.md` and a runnable example that works fully **offline**
(`Dataset.from_dict` + local temp files). Hub examples are present but only run when
`HF_PACK_ALLOW_NETWORK=1` is set. Without that flag the examples also set
`HF_HUB_OFFLINE=1` / `HF_DATASETS_OFFLINE=1` before importing `datasets`.

## Pinned library version

- `datasets==5.0.1` (verified locally with `pyarrow==25.0.1`, `numpy==2.5.3`, Python 3.13.5)
- `torch` is optional; the torch-format step is skipped when torch is not installed.
- The examples avoid APIs removed in datasets 3.x+ (loading scripts / `trust_remote_code`).

Install for local study (not part of default CI requirements):

```bash
python3 -m venv .venv-hf-datasets
.venv-hf-datasets/bin/pip install "datasets==5.0.1"
```

## Revision-pin policy

- Every Hub `load_dataset` call in this pack passes `revision=<full 40-char commit sha>`.
  Branch names (`main`) and tags are not accepted as pins.
- Pins live in `sources.json` (`repo_id`, `config`, `revision`, `license`, `split`), and the
  lesson code must use the same values (checked by `tests/test_study_pack_datasets.py`).
- Changing a pin requires re-reading the dataset card/license at the new sha and updating
  `sources.json` in the same change.
- No automatic downloads in CI: the test suite runs examples with the network flag unset.

## Regeneration

`tools/build_hf_capability_packs.py` only writes `study_packs/<id>/` for ids listed in
`config/huggingface-capability-packs.json` plus `study_packs/index.json`. This pack is
intentionally **not** listed there, so the builder never overwrites this folder.
