# evaluate

Hugging Face `evaluate` library study pack, plus the metric map that ties Buddy F0 and
edu benches to standard HF metrics. It is courseware and a wiring spec, not a score.

- train_allowed: false
- train_in_default_ci: false
- automatic_download_in_ci: false
- automatic weight download: no
- min_native_pass_rate: 1.0 (all offline lesson examples must pass)
- hand-authored: yes (not generated by `tools/build_hf_capability_packs.py`)
- license of library: Apache-2.0

## Pinned library version

- `evaluate==0.4.6` (latest on PyPI, checked 2026-09-28)

## What is here

- `metrics_adapter.py` calls `evaluate.load(...)` only when `HF_PACK_ALLOW_NETWORK=1`,
  otherwise uses pure-python `exact_match`, `accuracy`, `f1` and unbiased pass@k. Every
  result carries its `backend` so a fallback is never hidden.
- `bench_map.json` maps each Buddy bench family to HF metrics and cites the real repo
  path of its harness. Status is `spec_only`, `harness_exists_not_hf_wired`, or `missing`.
- `lessons/01_metric_basics` and `lessons/02_buddy_bench_scoring` are offline examples.

## Honest status

No Buddy bench is HF-wired yet. Three harnesses exist (`buddy/bench/scorecard.py`,
`benchmarks/tasks/first_four_mastery.json` with `benchmarks/buddy_benchmark_runner.py`,
`buddy/learning/bootcamp.py`). F0 families are specified in
`buddy/frontier/evaluation_matrix.md` but have no runner. Course mastery floors have no
in-repo harness. No F-tier claim may cite this pack until `evidence/` holds real runs.
