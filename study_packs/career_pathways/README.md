# Edu Career Pathways: majors to O*NET study plans

Maps bachelor's majors (2020 CIP codes) to O*NET-SOC occupations using the official O*NET CIP crosswalk, then writes one study plan per major (1,044 majors in two tiers, see Coverage): linked occupations with O*NET 31.0 Job Zones, the highest-importance O*NET knowledge areas and Essential Skills, 1 to 3 Job Zone-based entry-level targets, a 4-year outline, typical next steps, and 6 practice tasks with rubrics. The outline, next steps, and practice tasks are DreamCo-derived guidance, not O*NET data.

Fetch pinned sources: `python fetch_sources.py` (verifies sha256). Rebuild: `python build.py` (needs pandas, openpyxl; set `DREAMCO_GATE_TOOL` to `tools/license_provenance_gate.py` if it is not found automatically). Test: `pytest tests` (needs jsonschema for schema checks).

Inputs:
- `raw/` pinned official files (hashes in `raw/SOURCES.md`; raw data files are not committed).
- `authored/` checked-in DreamCo-authored sources that build.py reads, so builds are reproducible:
  - `practice_tasks_authored.json`: 162 practice tasks for the 27 authored majors. Each cites an O*NET 31.0 Task ID and O*NET-SOC code and has an original-wording paraphrase of the task's intent, an occupation-specific scenario prompt, a 3-criterion rubric for that scenario, and a reference answer outline.
  - `outline_topics.json`: per-major course-topic and practice mappings, keyed by CIP and O*NET element, for every element each authored outline uses.
  - `target_overrides.json`: manual entry-target overrides with reasons, plus review notes for majors kept as computed.
  - `coverage_rules.json`: which CIP codes get a plan (inclusion rule, excluded series, prefixes and title patterns, each with a reason).
  - `release_changes.json`: what changed versus the previous release (8cc1ce1), including each replaced practice-task citation with its reason; read by `regression.py`.
  - Authorship of all five: DreamCo-original, authored by Grok-Edu-Career-Pathways (AI), not human-reviewed.

Outputs:
- `data/major_to_onet.csv`, `data/majors_selected.json` (incl. tier, Job Zones, entry targets and target review), `data/practice_tasks.json`, `data/coverage.csv` (every CIP code in the crosswalk with included/excluded and the reason).
- `study_plans/<cip>_<slug>.md` (human layer) and sidecar folder `study_plans/<cip>_<slug>/` with `plan.json` (machine layer), `provenance.json`, `asset.json`, `candidate.json`, and `license_gate.json` (output of the DreamCo license/provenance gate).
- `data/dreamco_knowledge/evidence/regression/<asset_id>/<YYYYMMDD>-<NN>.json` (evidence record) and `.results.json` (item-level results), written by `regression.py`.
- Sources and hashes: `raw/SOURCES.md`. Test schemas snapshot: `tests/schemas/` (used when the live DreamCo schemas are not present).

Coverage and tiers:
- **authored** (27 majors, `build.MAJORS`): practice tasks, outline course topics and target review written for each major (see `authored/`).
- **generated** (1,017 majors): every other 6-digit CIP 2020 code in the crosswalk with at least one linked O*NET 31.0 occupation in Job Zone 4 or 5, after excluding non-bachelor programs (`authored/coverage_rules.json`). Excluded: CIP series 12, 28, 29, 32-37, 46-49, 53, 60, 61; 51.39 practical nursing; graduate/first-professional programs (law J.D. and LL.M., medicine, dentistry, optometry, chiropractic, veterinary, pharmacy apart from the authored 51.2001, physician assistant, physical and occupational therapy, audiology, divinity, graduate medical sciences); titles containing Technician, Assistant/Assisting, Aide, Apprentice or Police Science; and 133 codes whose linked occupations are all Manager, Chief, Postsecondary-faculty or All Other titles (no entry target can be named). 771 of the 1,948 crosswalk codes are excluded; `data/coverage.csv` lists each one with its reason.
- Generated plans say "Tier: **generated**" at the top, and `plan.json` and `majors_selected.json` carry `"tier": "generated"`. Their outline lists O*NET element names only, their entry targets are the unreviewed rule output (`entry_target_review.type = rule_only_not_reviewed`), and their 6 practice exercises use one DreamCo template around the cited O*NET task statement. The statement is quoted verbatim on an attributed quote line (USDOL/ETA, CC BY 4.0) and in `onet_task_statement`; it is O*NET content, not DreamCo-owned. Authored plans quote no O*NET task text. Generated plans have no regression evidence because they did not exist in the previous release.
- BLS Occupational Outlook Handbook data (typical entry education, median pay, outlook) is **not** included. On 2026-10-02 every official BLS endpoint tried from this box returned HTTP 403 "Access Denied": www.bls.gov/emp/ind-occ-matrix/occupation.xlsx, the occupational projections table page, www.bls.gov/ooh/, the OOH XML compilation, and download.bls.gov/pub/time.series/ep/ and /oe/. The fetch tool timed out on the same page. api.bls.gov responded but refused the request (keyless daily threshold) and does not carry the OOH fields anyway. No BLS figures were copied from secondary sources, because they could not be pinned and hashed from the official file.

Method notes:
- Entry targets: a rule first picks linked occupations in O*NET Job Zone 4 (typical bachelor's level), excluding titles containing Manager, Chief, Postsecondary, or All Other (and Supervisor, Director, or Treasurers and Controllers unless nothing else is linked), base `.00` codes first, ranked by correlation with the eligible occupations' average knowledge profile; fallback Job Zone 3, then 5, then 1-2. Every authored major's result was then reviewed for plausibility: 11 majors have a documented override in `authored/target_overrides.json` (for example, Computer Science now targets Software Developers, Software QA Analysts and Information Security Analysts instead of Database Architects), and the other 16 have a review note. Pharmacy uses Job Zone 5 (Pharm.D.), and Criminal Justice uses a Job Zone 3 supervisor title with a caveat, because its only crosswalk links are supervisors, faculty, and an All Other code.
- Practice tasks reference an O*NET 31.0 Task ID and O*NET-SOC code. O*NET task text is not reproduced: tests check that no run of 5 or more words from any O*NET 31.0 task statement, Job Zone reference text, or occupation description appears in the authored fields or in the plan files (occupation titles excepted).
- Typical next steps cite O*NET Job Zone numbers only; Job Zone names and descriptions are not quoted.
- Regression evidence: `python regression.py --baseline-ref 8cc1ce1 --repo <git clone of Dreamcobots>` compares each plan in this build with the previous release, item by item. It checks linked occupation codes (title and Job Zone), knowledge and skill importance values and ranks, entry targets (presence and order), practice-task citations (practice id, O*NET-SOC code, task ID), that each citation is a real task of a linked occupation, license-gate checks (a check that passed must still pass), and O*NET text leakage in the plan (zero 5-word runs). Every difference must be explained by `authored/target_overrides.json` or `authored/release_changes.json`. Score = fraction of items that are preserved, improved, or changed with a reason; threshold 1.0, and any leakage fails the record. The record follows `config/evidence_provenance_schema.json` (source_type dreamco_experiment, transformation original_evaluation, source_reference = the asset's integrity_hash, integrity_hash = sha256 of the results file). build.py links a record into `asset.json` `validation_evidence_ids.regression` only if its source_reference matches the current plan hash, its hash matches the results file, and it passed. Regression ran before the evidence was linked, so its gate comparison uses the pre-link gate files. A test checks that the comparator flags dropped links, unexplained targets, changed scores, swapped citations, gate regressions and leaked text.

## Status and open items

- O*NET 31.0 is pinned for this pack (DP-ONET): every O*NET file comes from `db_31_0_csv` and is sha256-pinned. The fleet O*NET ingest is still pinned to 30.3, and aligning the two is an open decision. O*NET 31.0 split Skills into Essential Skills and Transferable Skills; this pack uses Essential Skills.
- Merchant review of the previous release (8cc1ce1): CS sample scored 66.0 (quality_review); 75 is needed for sale. This rebuild addresses the reviewer's points: templated practice tasks replaced by authored scenarios, stock outline phrases replaced by per-major topics, entry targets reviewed, Job Zone text no longer quoted, and regression evidence added. It has not been re-scored.
- Coverage: 1,044 majors (27 authored, 1,017 generated). Generated plans are template output and have not been reviewed. Authoring more majors would mean adding them to `build.MAJORS` and `authored/`.
- BLS OOH perspective: not added. Every official BLS source tried from this box returned 403 (see Coverage and tiers).
- Validation evidence: each of the 27 authored plans has two regression records against 8cc1ce1, all passed with score 1.0. `20261002-01` was run after the Phase 1 rebuild. `20261002-02` was run after the coverage expansion and shows the authored plans are unchanged by it; its gate comparison already reflects the linked -01 record. Generated plans have none. The sandbox, benchmark and holdout lists are empty on purpose: this box has no independent model API key and no human graders, and a self-graded run would not be independent evidence. Regression evidence shows this release did not lose or silently change links, targets, values or citations. It does not measure learning outcomes or plan quality.
- License gate (tools/license_provenance_gate.py): all 1,044 plans pass every rights check (rights ceiling approved_for_sale), and every outcome is approved_for_private_use. All plans fail two sale-scope checks: no dataset scorecard score and no owner approval. `synthesis_asset_record` is a warning for the 27 authored plans (only one perspective, official_documentation) and a failure for the 1,017 generated plans (no validation evidence).
- All authored content was written by an AI agent and has not been human-reviewed or piloted with learners.
- Owner approval is pending. build.py never sets it.
- `evidence/scorer_cs.txt` and `evidence/scorer_input_cs_selfassessed.json` are the historical builder self-assessment of the 8cc1ce1 CS plan (66.75), superseded by the merchant's 66.0; they were not updated for this rebuild.
- Raw source files are not committed. `fetch_sources.py` downloads them and checks their hashes.
