# Use this Easy GitHub pattern on any repository

Copy `buddy/easy_github/` into another project to give beginners the same feeling as experienced operators.

## Minimum files to copy

1. `WORDS.md` — jargon → common words
2. `START_HERE.md` — 10-minute on-ramp
3. `MAP.md` — rewrite folder names for *that* project
4. `SAY_THIS.md` — sentences people can copy
5. `glossary.json` + `buddy_easy_github.py` — translator

## Rules that make beginners feel experienced

1. One front door (`START_HERE.md`) above all other docs
2. Every hard word appears next to an easy word, never alone
3. Every dangerous action asks for a yes
4. Robot tickets are not treated as human tickets
5. A catalog is not claimed as a live product
6. Secrets never go in chat or in the website
7. The map is short enough to read in two minutes

## Optional next layer

- Rename GitHub labels: `ticket`, `change-request`, `robot-check`
- Add an issue template titled "Thing to fix" instead of "Bug report"
- Add a PR template titled "Please review this change"
