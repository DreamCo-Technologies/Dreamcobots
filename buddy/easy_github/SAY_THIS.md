# Sentences you can say to Buddy

## Save and send

- Save my work
- Send my work up
- Get the latest copy
- Make a named copy called practice

## Problems and reviews

- What's broken?
- Open a ticket: the button on the bot page does nothing
- Review this change
- This ticket is noise, close the copies
- Keep the real human tickets

## Checks

- Did the robot check pass?
- Why did the check fail?
- Run the easy tests only

## Bots

- Which helper should do this?
- Show Buddy, Deal, Build, and Content
- Add something I want this bot to learn
- Is this bot really live or just listed?

## Learning

- What reasoning tricks can we use?
- Pick a learning plan for debugging
- Show the sell packs for reasoning

## Safety

- Don't publish yet
- Don't spend money
- Don't delete anything
- Ask me before you send this live
