# Easy map of this project

Think of the repository as a house. Buddy knows the rooms.

| Easy name | Folder | What it is |
|-----------|--------|------------|
| Front door | `START_HERE` files + `README.md` | How to enter |
| Buddy's desk | `buddy/` | The helper that routes work |
| Easy GitHub | `buddy/easy_github/` | Plain-language GitHub layer |
| Learning lab | `buddy/learning/` | How Buddy studies and improves |
| Bot catalog | `App_bots/` | Official list of specialist bots |
| Bot pages | `bots/` | One short page per specialist |
| Website | `website/` and `client/` | What people see |
| Workshop | `tools/` | Scripts that clean, check, build |
| Robot checks | `.github/workflows/` | Automatic tests |
| Rules | `AGENTS.md`, `docs/` | How helpers must behave |
| Reports | `reports/` | Written results |
| Original work | `original-bots/`, `bots/` drop folders | Nothing important was thrown away |

## If you are lost, say

- "Show the map"
- "Where do bot lists live?"
- "Where do I add a lesson for a bot?"
- "Where are the robot checks?"
