# Easy words instead of GitHub jargon

Buddy speaks **everyday English**. GitHub still uses the technical words underneath. You never have to say the hard words first.

| You can say | Buddy means | GitHub word |
|-------------|-------------|-------------|
| project / home | the whole codebase | repository / repo |
| save my work | write files + record the change | commit |
| send my work up | upload the save to GitHub | push |
| get the latest | download newest work | pull / fetch |
| problem / ticket / thing to fix | a tracked request | issue |
| change request / review this | proposed update for review | pull request (PR) |
| team check / robot check | automated test on GitHub | GitHub Action / CI |
| copy of the work | a named line of work | branch |
| main copy | the official line | main / default branch |
| approve | owner says yes | merge |
| undo | go back to an earlier save | revert |
| secret key | password-like value, never shared | secret / token |
| website | public pages | GitHub Pages |
| helper bot | Buddy or a specialist | agent / workflow |
| note for later | short reminder in the project | comment |
| who can touch this | permission | collaborator / access |
| release | a named finished version | release / tag |

## Talk to Buddy like this

- "Save this and send it up."
- "What's broken?"
- "Ask someone to review my change."
- "Did the robot check pass?"
- "Show me the easy map of this project."
- "Fix the noise tickets, keep the real ones."
