# Realistic goals

These are the goals the scorecard can check. They are not a plan to match Astra.

1. Keep the 13 gate checks passing.
2. Finish the missing reading ranges, 301–400 and 601–1000, before calling the school complete.
3. Train only an open model the customer owns, on a machine they control.
4. Publish a score on a hidden public exam before any comparison with another model.

Astra is a frontier model. This repository does not contain those weights, and a made-up distance would not be a benchmark.
