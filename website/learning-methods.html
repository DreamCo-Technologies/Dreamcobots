Contrastive learning

Contrastive learning pulls two views of the same thing together and pushes a different thing away. That matches the training note: two or more views of one part, then your own line. This page does not run the training.

  • SimCLR — two changed views of one image are the matching pair. Many other images are the non-matches.
  • MoCo — keeps a queue of older non-matches so the comparison stays large without a huge batch.
  • CLIP — the matching pair is an image and its caption.
  • SimCSE — two passes of the same sentence are the matching pair.
  • Supervised contrastive learning — views with the same label are matches.

Related, but not contrastive, because they do not use non-matches: BYOL.

Hugging Face sets used for this kind of comparison

These cards exist. Read the license before training. The files are not stored here.

  • all-nli — sentence pairs labeled as the same meaning or not.
  • MS MARCO hard negatives — a question, a useful passage, and passages that only look useful.
  • Flickr30k — photos with several captions. The card limits how it can be used.
