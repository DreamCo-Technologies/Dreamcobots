Distillation course

Goes with the Buddy bootcamp. A large model teaches a smaller one. This page trains the method, not a frontier model.

Bootcamp Train Hub Techniques

Lesson 1. What distillation is

The teacher produces answers. The student is trained to match those answers, not only the final label. Soft targets keep the teacher's uncertainty.

Lesson 2. Teacher, student, data

  1. Pick a teacher you are allowed to query.
  2. Pick a smaller student.
  3. Collect prompts you actually use.
  4. Save teacher outputs. Do not train on private chats unless the user allowed storage.

Lesson 3. Loss

Match the teacher's token distribution, or match the final answer if you only have text. Temperature above 1 softens the teacher. A hard-label term can be mixed in.

Lesson 4. Try a tiny distill

Teacher answer and student draft. Score overlap. This is a check, not a weight update.

Lesson 5. Checks before you ship

  • Hold out prompts the student never saw.
  • Compare student to teacher and to the hard label.
  • Watch for copied private text.
  • Do not claim the student equals the teacher.

Targets and temperature

Hard target: the correct final answer, one label. The student only learns the winner.

Soft target: the teacher's probability over many answers. The student learns which answers were close.

Temperature: above 1 flattens the teacher distribution so rare-but-plausible answers still teach. At 1 you keep the teacher's sharpness. Below 1 makes the teacher more peaked.

Real example: a support bot teacher says "refund" at 0.7 and "exchange" at 0.2. A hard target only teaches refund. A soft target at temperature 2 also teaches that exchange was reasonable.

Real-world examples

  • Phone support: distill a large model into a small on-device model for common refund questions.
  • Code helper: teacher writes full patches; student learns short, safe diffs.
  • Clinic intake: teacher explains; student must match the explanation without adding a diagnosis.
  • Store bot: teacher answers shipping questions; student is checked on held-out orders.
