Learn the GitHub words when you're ready
Project → Repository
The files, history, and conversations for a project.
Thing to do → Issue
A recorded idea, question, or problem.
Change to review → Pull request
A proposal to add changes to another version of the project.
Working version → Branch
A separate line of work where you can try changes.
Saved change → Commit
A recorded snapshot with a message explaining the change.
Bring changes together → Merge
Add the reviewed work into the destination version.
Build checks → Actions
Automated jobs that can test, package, or publish work.
Publish → Deploy
Make a particular version available in its running environment.
