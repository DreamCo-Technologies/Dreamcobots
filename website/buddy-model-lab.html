Path toward stronger Buddy models
  1. Define held-out tasks for coding, reasoning, retrieval, multimodal work, instruction following and safe tool use.
  2. Run licensed baseline models and retain answers, latency, resource use and human-reviewed scores.
  3. Improve retrieval and adapters; only fine-tune on consented data with a separate test set.
  4. Compare against named baselines on the same tasks and hardware. Publish limitations and failed cases.
