Assign a worker

Name the job. Buddy picks a worker and a personality from the presets already in the repository. You can change both before you save. A preset is a setting. It is not a trained model, and it is not a real person.

    Vibe an app

    Type what the app should do. Buddy writes a preview on this page. It does not publish to an app store, and it is not the whole Replit service.

    Pull requests

    A pull request is safe to merge only when GitHub says it does not conflict and every finished check passed. Open pull requests were still failing checks, so none were merged.
