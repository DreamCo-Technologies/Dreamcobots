Owner setup

  1. Create Google and Apple web OAuth clients.
  2. Register the displayed callback URLs exactly.
  3. Set server-only environment variables: AUTH_SESSION_SECRET, Google client ID/secret, Apple client ID/secret, and OAUTH_REDIRECT_BASE_URL.
  4. Deploy the Buddy backend over HTTPS, then test each provider.
