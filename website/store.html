53 GitHub features, in plain words

Project folder

GitHub calls this Repository. A project folder is the box that holds your files, notes, and history.

Save point

GitHub calls this Commit. A save point is a snapshot of the files, with your note about what changed.

Side copy

GitHub calls this Branch. A side copy lets you try a change without touching the main copy.

Ticket

GitHub calls this Issue. A ticket is a written request: a bug, a task, or a question.

Change request

GitHub calls this Pull request. A change request asks to bring a side copy into the main copy after someone looks at it.

Check the change

GitHub calls this Pull request review. A check is a person, or a robot, saying what is fine and what is not before the change lands.

Open conversation

GitHub calls this Discussion. An open conversation is for questions and ideas that are not a ticket.

Task board

GitHub calls this Project. A task board lines up tickets in columns such as to do, doing, and done.

Long notes

GitHub calls this Wiki. Long notes are extra pages of explanation that live next to the project.

Numbered ship

GitHub calls this Release. A numbered ship is a marked version people can download.

Public site

GitHub calls this GitHub Pages. A public site is a web page built from files in the project.

Robots

GitHub calls this GitHub Actions. Robots run checks or other jobs when you save or when you press a button.

Robot recipe

GitHub calls this Workflow. A robot recipe is the file that says when a robot runs and what it does.

Saved robot file

GitHub calls this Artifact. A saved robot file is something a robot kept, such as a report or a built app.

Shipped library

GitHub calls this GitHub Packages. A shipped library is a packaged copy of code other projects can install.

Cloud work room

GitHub calls this Codespaces. A cloud work room is a computer in the browser with the project already open.

GitHub's helper

GitHub calls this GitHub Copilot. GitHub's helper suggests code inside GitHub. Buddy is not that product.

Try a model in GitHub

GitHub calls this GitHub Models. GitHub lets you try some models next to a project. That does not give you their weights.

Small snippet

GitHub calls this Gist. A small snippet is one or a few files shared without a full project.

Ping

GitHub calls this Webhook. A ping is a message GitHub sends to your address when something happens, such as a new ticket.

Ask with a link

GitHub calls this REST API. Asking with a link means a program can read or change GitHub by calling a web address.

Ask for exact fields

GitHub calls this GraphQL API. Asking for exact fields lets a program request only the pieces it needs.

Terminal app

GitHub calls this GitHub CLI. The terminal app is the gh command. It talks to GitHub from a keyboard.

Desktop app

GitHub calls this GitHub Desktop. The desktop app is GitHub as a program on your computer, without the terminal.

Phone app

GitHub calls this GitHub Mobile. The phone app lets you read tickets and changes on a phone.

Team home

GitHub calls this Organization. A team home holds many projects and the people who work on them.

Group

GitHub calls this Team. A group is a named set of people inside the team home.

Who is allowed

GitHub calls this Repository roles. Who is allowed says who can read, write, or manage a project.

Landing rules

GitHub calls this Ruleset. Landing rules can require a check or a review before a change becomes the main copy.

Hidden password

GitHub calls this Actions secret. A hidden password is a value robots can use. It should not be written in the project files.

Ship place

GitHub calls this Environment. A ship place is a named target, such as a test site or a live site, with its own rules.

Library updater

GitHub calls this Dependabot. The library updater opens change requests when a library you use has a newer version.

Leaked-password finder

GitHub calls this Secret scanning. The leaked-password finder looks for keys that were saved in the project by mistake.

Risk finder

GitHub calls this Code scanning. The risk finder looks through code for known kinds of mistakes.

Public warning

GitHub calls this Security advisory. A public warning tells users about a security hole and the fix.

Charts

GitHub calls this Repository insights. Charts show activity such as saves and visitors. They are not a grade.

Alerts

GitHub calls this Notifications. Alerts tell you when someone mentions you or a ticket changes.

Find

GitHub calls this Search. Find looks across code, tickets, and change requests.

Pay a maintainer

GitHub calls this GitHub Sponsors. Pay a maintainer is GitHub's way to fund someone whose project you use.

App shop

GitHub calls this GitHub Marketplace. The app shop lists tools you can add to a project. Read what each one is allowed to do.

House rules

GitHub calls this Code of conduct. House rules say how people should treat each other on the project.

Landing line

GitHub calls this Merge queue. A landing line waits until checks pass, then brings changes in one at a time.

Limited key

GitHub calls this Personal access token. A limited key lets a program act as you, only for the jobs you ticked. Do not paste it in public files.

Who did what

GitHub calls this Audit log. Who did what is a record of important actions in a team home.

Class assignments

GitHub calls this GitHub Classroom. Class assignments hand each student a copy of a starter project.

GitHub's lessons

GitHub calls this GitHub Skills. GitHub's lessons are short courses GitHub hosts. They are not Buddy's boot camp.

Ticket form

GitHub calls this Issue forms. A ticket form asks set questions so a new ticket is easier to read.

Deadline bucket

GitHub calls this Milestone. A deadline bucket groups tickets you want finished together.

Tag

GitHub calls this Label. A tag is a colored word on a ticket, such as bug or help wanted.

Big files

GitHub calls this Git LFS. Big files stores large binaries beside the project instead of inside every save.

Company GitHub

GitHub calls this GitHub Enterprise. Company GitHub is the paid plan for a whole company, with extra admin controls.

Robot machines

GitHub calls this Actions runners. Robot machines are the computers that run the recipes. GitHub hosts some. You can host your own.

Build proof

GitHub calls this Artifact attestations. Build proof records how a file was produced so others can check it.

Buddy translates the words. GitHub still does the work.
