Buddy Control Panel

Every recurring job Buddy's helpers and GitHub Actions do for DreamCo is registered here. Each one maps to a workflow, a risk tier, and the inputs it accepts. Press Run with Buddy to open a prefilled GitHub issue; the Buddy command router checks who you are, validates the job and inputs against the registry, dispatches the workflow on main, and comments back with the run link.

Runs require an authorized operator. This page is public and static: it holds no tokens and cannot run anything by itself. The router only acts for GitHub users listed as Buddy operators who also have write access. Owner-approval jobs need an owner. Money/Stripe jobs and anything that deletes or bulk-closes are never runnable from here.
