# 180 ways to use Grok Bot with Buddy

These are proposed task handoffs, not a claim that 180 integrations are already installed. Grok Bot documentation describes a persistent computer with a browser, files, terminal, app access, and reusable routines. Its success depends on granted access and the tools available in your account. [Official Grok Bot documentation](https://docs.x.ai/grok-bot/overview).

The xAI API separately supports configured search, code execution, retrieval, and custom tool calls. A Grok Bot subscription does not establish that this website has an API integration. [Official xAI tool documentation](https://docs.x.ai/developers/tools/overview).

Buddy currently provides the website's 3D concept viewer, browser-local project briefs and parts ledger, specialist directory, and links to its existing tools. Live Grok execution from Buddy has not been verified. Medical tasks below support literature organization and research planning, following the [FDA development pathway](https://www.fda.gov/patients/learn-about-drug-and-device-approvals/drug-development-process); they do not establish a new medicine or clinical efficacy.

A practical handoff: “Complete [task] for DreamCo. Inspect the relevant source files first. Produce an editable deliverable, cite external sources, distinguish assumptions from evidence, and report exactly what was tested. Prepare external actions for my review unless I already authorized them. Never invent dimensions, simulation results, or clinical evidence.”
