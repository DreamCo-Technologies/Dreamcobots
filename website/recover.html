Recovery systems

Buddy does not have a “make it green” switch. Failures enter one incident bus and are routed to a specialist lane that already exists in this repository. Old failed Actions stay historical. Missing evidence stays blocked. Money and secrets are never auto-repaired.

File a problem

Buddy routes the text to a lane. “Make everything green” goes to Detect and will not rewrite history.

GitHub already runs Actions Failure Sweep, PR Recovery Engine, Keep Green, and Daily Branch Health. This desk is the map that makes them one system. It does not merge to main.
