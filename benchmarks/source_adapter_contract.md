# Buddy Source Adapter Contract

A source adapter converts an authorized external knowledge source into durable, testable Buddy capability packages.

## Adapter stages

1. **Discover** — identify canonical source and authoritative entry points.
2. **Verify** — confirm access method, licensing/terms and scope.
3. **Acquire** — retrieve only permitted material.
4. **Fingerprint** — record URL/version/content hashes and retrieval timestamp.
5. **Extract** — parse HTML, PDF, transcript, book, dataset, code or API data.
6. **Normalize** — convert to common concepts, entities, procedures and examples.
7. **Connect** — link concepts to prerequisites and related sources.
8. **Package** — create machine-readable capability packages.
9. **Generate** — produce beginner, intermediate, advanced, transfer and adversarial tasks.
10. **Sandbox** — construct the smallest isolated environment needed for practical testing.
11. **Evaluate** — run deterministic and model-assisted tests.
12. **Remediate** — identify the actual failure type and prescribe targeted learning.
13. **Retest** — repeat with a new task variant.
14. **Regression** — make mastered tasks permanent regression tests.
15. **Promote** — only evidence-backed capabilities advance to mastered/production-proven.

## Learning modes

Buddy should learn through as many compatible modes as the source supports:

- reading
- watching
- listening
- coding
- building
- debugging
- explaining
- teaching-back
- retrieval practice
- spaced repetition
- comparison
- synthesis
- simulation
- experimentation
- reverse engineering of authorized examples
- benchmark execution
- peer/agent critique
- human feedback
- failure analysis
- transfer to unfamiliar tasks

## Speed rule
Never maximize raw ingestion at the expense of validation. Parallelize independent acquisition and evaluation, but preserve source provenance and capability boundaries.

## Safety rule
The adapter must not bypass paywalls, authentication, robots/access controls, licensing restrictions or repository permissions. Public does not automatically mean unrestricted reuse.
