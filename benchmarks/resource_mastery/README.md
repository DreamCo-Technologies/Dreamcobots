# Resource mastery sandbox

Scans every URL resource in `config/` and `benchmarks/` and runs it locally.

Buddy can explain and route each service without calling a third party. Third-party services stay offered and benchmarked. A passing run is catalog sandbox mastery, not production mastery. The repo policy forbids manufactured mastery scores.

```bash
python3 benchmarks/resource_mastery/sandbox.py --summary-only
python3 -m unittest benchmarks.resource_mastery.test_sandbox
```
