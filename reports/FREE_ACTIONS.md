# Free actions Buddy can use

No logins are stored. A row is available only after you connect that account.

## chatgpt
- draft a prompt
- summarize a note
- compare two answers

## github
- open an issue
- read a public repo
- run a free workflow
- publish Pages

## grok
- scan a repo
- write a report
- rank a model list

## claude
- review a diff
- explain an error
- draft a test

## codecademy
- study a free lesson with permission
- save the user's own note
