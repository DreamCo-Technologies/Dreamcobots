# Buddy resource list

This is a study index. It is not a frontier model, and a row is not a completed run.

## Near network

- Record the source, the target, and the permission before a call.
- Keep a paid model off the route until that account is connected.
- Retry a timeout once, then record the failure.
- Do not store a secret in the repo.

## Topology

- Pages root and website folder are two paths to the same files.
- Bots, App_bots, and legacy profiles are separate lists.
- A route needs a measured score for that task.
- A missing file is a gap. A duplicate name is reported, not deleted.

## Ontology

- A bot has a slug, a display name, a source file, and a readiness state.
- Production ready requires an adapter, a sandbox run, auth, and telemetry.
- Accounted means the file is listed. It does not mean the bot ran.
- A capability row is a target, not a proven skill.

## Learning tactics

- One user question can add a counterexample and a measured view.
- A course site is studied only after permission.
- Two passes are required before a performance claim.
- The median latency is the reported time.
