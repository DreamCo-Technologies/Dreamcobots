# DreamCo beginner router

This Space is a word matcher over 200 written replies. It is not a leaderboard model and it does not trade, mine, or spend.

The GitHub workflow `.github/workflows/sync-to-huggingface.yml` uploads this folder with the official `huggingface/hub-sync` action. It runs only when someone starts it by hand, and only if the repository secret `HF_TOKEN` exists.
